# login-altus-engenharia
Tela de login responsiva desenvolvida com HTML e CSS puro, usando glassmorphism e tema noturno

Essa tela de login, foi criada pensando em login de funcionários da empresa fictícia Altus Engenharia.

As tecnologias usadas nesses progetos foram: - HTML5, CSS3,[Boxicons](https://boxicons.com/) e [Google Fonts - Poppins](https://fonts.google.com/specimen/Poppins).

Funcionalidades aplicadas:Interface moderna e centralizada, efeito *vidro fosco* (glassmorphism) no formulário, Ícones integrados nos campos de usuário e senha, estilo "dark mode" com fundo estrelado com prédios, Campo para lembrar senha (checkbox), Link "Esqueci minha senha", Botão com efeito hove, Link para cadastro de novos usuários.
